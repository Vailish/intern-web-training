# 01. AI 큰 그림과 용어

> 🎯 목표: AI, 머신러닝, 딥러닝, 생성형 AI, LLM의 관계를 **그림 하나로** 설명하고, 회의에서 나오는 AI 용어를 알아듣는다.

---

## 도입 — 이 두 프로그램은 무엇이 다를까?

스팸 메일을 걸러내는 프로그램을 만든다고 해 봅시다.

**방법 A — 사람이 규칙을 짠다**
```java
if (title.contains("무료") || title.contains("당첨") || sender.endsWith(".xyz")) {
    return SPAM;
}
```

**방법 B — 예시를 보여 주고 규칙을 스스로 찾게 한다**
```
스팸 메일 10만 개 + 정상 메일 10만 개  ──학습──▶  "스팸 판별기"(모델)
```

- 방법 A는 우리가 지금까지 배운 **일반 프로그래밍**입니다. 규칙을 사람이 다 적어야 하고, 스패머가 "무.료"라고 쓰면 뚫립니다.
- 방법 B가 **머신러닝**입니다. 규칙을 사람이 적지 않고, **데이터에서 패턴을 학습**합니다.

> 💡 핵심 차이: 일반 프로그래밍은 **규칙 → 결과**, 머신러닝은 **데이터 + 결과 → 규칙(모델)**.

## 1. 큰 그림 — 포함 관계

```
┌──────────────────────────────────────────────────────────────┐
│ AI (인공지능)  사람처럼 판단·인식하는 기술 전체               │
│   예: 규칙 기반 전문가 시스템, 게임 AI, 길찾기               │
│  ┌────────────────────────────────────────────────────────┐  │
│  │ 머신러닝 (ML)  데이터에서 규칙을 학습                   │  │
│  │   예: 스팸 필터, 집값 예측, 추천                        │  │
│  │  ┌──────────────────────────────────────────────────┐  │  │
│  │  │ 딥러닝 (DL)  층이 깊은 신경망으로 학습             │  │  │
│  │  │   예: 얼굴 인식, 음성 인식, 번역                   │  │  │
│  │  │  ┌────────────────────────────────────────────┐  │  │  │
│  │  │  │ 생성형 AI  새 콘텐츠(글·그림·코드)를 생성   │  │  │  │
│  │  │  │  ┌──────────────────────────────────────┐  │  │  │  │
│  │  │  │  │ LLM (대규모 언어 모델)                │  │  │  │  │
│  │  │  │  │  ChatGPT, Claude, Gemini 등의 엔진   │  │  │  │  │
│  │  │  │  └──────────────────────────────────────┘  │  │  │  │
│  │  │  └────────────────────────────────────────────┘  │  │  │
│  │  └──────────────────────────────────────────────────┘  │  │
│  └────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────┘
```

- **"AI 도입"이라는 말이 꼭 LLM을 뜻하지는 않습니다.** 공공·SI 현장에서는 지금도 수요 예측, 이상 탐지 같은 **전통적인 머신러닝**이 많이 쓰입니다.
- 요즘 뉴스의 "AI"는 대부분 **생성형 AI, 그중에서도 LLM**을 가리킵니다. 이 모듈도 LLM 위주로 다룹니다.

## 2. 학습(Training)과 추론(Inference)

| | 학습 (Training) | 추론 (Inference) |
|---|---|---|
| 무엇 | 데이터로 모델을 **만드는** 단계 | 만든 모델을 **사용하는** 단계 |
| 비유 | 수험생이 몇 년간 공부하기 | 시험장에서 문제 풀기 |
| 비용 | 매우 큼 (GPU 수천 장, 수개월) | 요청 1건당 작음. 대신 **요청 수만큼** 계속 듦 |
| 누가 | OpenAI, Anthropic, Google, 네이버, LG 같은 **모델 회사** | **우리 같은 웹 개발자** (API로 호출) |

> 🏢 **실무 연결**: 웹 개발자가 하는 일은 거의 다 **추론 쪽**입니다. 모델을 직접 학습시키는 일은 드뭅니다.
> "AI 개발자"와 "AI를 활용하는 웹 개발자"는 다른 직무라는 점을 알아 두세요.

**중요한 결과 하나**: 모델은 **학습이 끝난 시점까지의 데이터**만 압니다. 이 시점을 **지식 컷오프(knowledge cutoff)** 라고 합니다.
그래서 AI는 최신 라이브러리 버전이나 최근 뉴스를 모르거나, **안다고 착각**하기도 합니다. (03, 04 문서에서 다시 다룹니다.)

---

## 3. 학습 방식 세 가지 (상식 수준)

| 방식 | 설명 | 예 |
|---|---|---|
| **지도학습** | 정답이 붙은 데이터로 학습 | "이 메일은 스팸" 라벨 → 스팸 분류 |
| **비지도학습** | 정답 없이 데이터의 구조를 찾음 | 고객을 비슷한 그룹으로 묶기 |
| **강화학습** | 행동하고 보상을 받으며 학습 | 알파고, 게임 AI. LLM을 사람 취향에 맞게 다듬을 때도 사용 |

LLM은 이것들을 섞어 만듭니다. ① 인터넷 규모의 글로 **다음 단어 맞히기**를 학습(사전학습)하고, ② 질문-좋은 답 예시로 다듬고, ③ 사람의 피드백으로 강화학습을 합니다.

## 4. 회의에서 들리는 용어집

| 용어 | 한 줄 설명 | 자세히 |
|---|---|---|
| **모델** | 학습 결과물. "GPT", "Claude" 같은 이름이 모델(또는 모델 계열) 이름 | 01 |
| **파라미터** | 모델 내부의 숫자(가중치) 개수. 많을수록 대체로 똑똑하지만 비싸고 느림 | 01 |
| **LLM** | Large Language Model. 대량의 글로 학습한 언어 모델 | 01, 03 |
| **트랜스포머** | 2017년 구글 논문에서 나온 신경망 구조. 현재 LLM의 기반 | 02 |
| **프롬프트** | AI에게 보내는 입력(질문, 지시) | 03, 04 |
| **토큰** | LLM이 글을 쪼개서 처리하는 단위. **과금 단위**이기도 함 | 03 |
| **컨텍스트 윈도우** | 한 번에 넣을 수 있는 토큰의 최대량. AI의 "작업 기억" | 03 |
| **할루시네이션(환각)** | 사실이 아닌 내용을 그럴듯하게 만들어 내는 현상 | 03, 06 |
| **임베딩** | 글의 의미를 숫자 배열(벡터)로 바꾼 것. 비슷한 의미끼리 가까움 | 03 |
| **RAG** | 검색 증강 생성. 우리 문서를 검색해 프롬프트에 넣어 답하게 하는 방식 | 03, 05 |
| **파인튜닝** | 이미 학습된 모델을 우리 데이터로 추가 학습 | 03 |
| **멀티모달** | 글뿐 아니라 이미지·음성·영상도 입력·출력 | 02 |
| **추론 모델(reasoning model)** | 답하기 전에 내부적으로 "생각" 단계를 거치는 모델. 느리고 비싸지만 어려운 문제에 강함 | 02 |
| **에이전트** | 목표를 받고 스스로 도구(검색, 파일, 코드 실행)를 쓰며 여러 단계를 수행하는 AI | 02, 03 |
| **MCP** | Model Context Protocol. AI가 외부 도구·데이터에 접속하는 **표준 규격** | 02, 03 |
| **오픈 웨이트 모델** | 모델 가중치를 공개해 직접 내려받아 돌릴 수 있는 모델 (예: Llama 계열) | 02 |
| **온프레미스 / 로컬 LLM** | 외부 API 대신 **자기 서버**에서 모델을 돌림. 망분리 환경에서 중요 | 02, 06 |

> ⚠️ **"추론"이라는 단어의 두 가지 뜻**: 표의 2장에서 말한 추론(Inference)은 "모델 사용"이고, 추론 모델(Reasoning)의 추론은 "생각하기"입니다. 한국어로는 같은 단어라서 문맥으로 구분해야 합니다.

## 함정

| 오해 | 실제 |
|---|---|
| "AI가 내 질문을 이해하고 생각해서 답한다" | LLM은 **다음에 올 그럴듯한 토큰**을 확률로 고릅니다. "이해"처럼 보이는 행동은 그 결과입니다 (03) |
| "AI는 인터넷을 실시간으로 안다" | 기본 모델은 **지식 컷오프 이후를 모릅니다.** 검색 기능이 붙은 경우만 예외 |
| "대화하면 AI가 학습해서 똑똑해진다" | 대화 중 기억은 **컨텍스트 안에서만** 유지됩니다. 모델 자체가 실시간으로 다시 학습되지는 않습니다. 챗봇의 "메모리" 기능도 저장해 둔 메모를 다음 대화의 컨텍스트에 다시 넣어 주는 방식입니다. 다만 **서비스 약관에 따라 입력이 향후 학습에 쓰일 수 있으므로** 민감정보를 넣으면 안 됩니다 (06) |
