# 09. CS — 웹 개발자를 위한 컴퓨터 과학 기초

CS(Computer Science) 기초를 **"면접 암기 과목"이 아니라 "운영에서 터지는 버그의 원인"** 으로 배웁니다.
지금까지 만든 스프링 앱 밑에서 실제로 무슨 일이 일어나는지 — CPU, 메모리, 스레드, 잠금, 인덱스 — 를 직접 실행해 보며 확인합니다.

> 🎯 **이 모듈을 마치면 할 수 있는 것 한 가지**
> "로컬에선 멀쩡했는데 운영에서만 숫자가 틀려요 / 남의 이름이 보여요 / 서버가 멈췄어요 / 조회가 느려요" 를 듣고
> **"레이스 컨디션 / 싱글톤 상태 / 데드락 / 인덱스 미사용"** 중 무엇을 의심할지 말할 수 있습니다.

## CS 전체 지도 — 이미 배운 곳과 이 모듈의 범위

CS는 범위가 넓습니다. **이 교육과정에 이미 있는 분야는 링크로 연결**하고, 이 모듈은 빠져 있던 부분을 채웁니다.

| CS 분야 | 어디서 배우나 | 비고 |
|---|---|---|
| 네트워크 (TCP/IP, DNS, HTTP) | [07_Network](../07_Network/README.md) | 이미 완료 |
| 자료구조·알고리즘·시간복잡도 | [05_algorithm](../05_algorithm/README.md) | 이미 완료 |
| 보안 (인증·세션·토큰) | [Spring/Security](../Spring/Security/README.md) | 이미 완료 |
| **컴퓨터 구조** (CPU·메모리 계층·캐시) | **이 모듈 01** | 신규 |
| **데이터 표현** (정수·실수·문자 인코딩) | **이 모듈 02** | 신규 |
| **운영체제** (프로세스·스레드·스레드 풀) | **이 모듈 03** | 신규 |
| **동시성** (레이스 컨디션·락·데드락) | **이 모듈 04** | 신규 — 가장 중요 |
| **JVM 메모리** (스택·힙·GC) | **이 모듈 05** | 신규 |
| **DB 내부** (격리 수준·갱신 분실·인덱스) | **이 모듈 06** | [03_Database](../03_Database/README.md)의 심화 |

> 운영체제의 파일 시스템·가상 메모리 세부, 컴파일러 이론 같은 주제는 일부러 뺐습니다. 웹 개발 실무에서 **원인 진단에 직접 쓰이는 것**만 골랐습니다.

## 샘플 코드 — `샘플/cs-lab`

Gradle 없이 **파일 하나씩 바로 실행**하는 순수 자바 실습 10개입니다. 사용법은 [샘플/cs-lab/README.md](./샘플/cs-lab/README.md).

```powershell
cd 09_CS\샘플\cs-lab
java "-Dfile.encoding=UTF-8" RaceConditionLab.java
```

> `"-Dfile.encoding=UTF-8"` 은 **따옴표째** 붙이세요. 빼면 한글이 깨지는데, 그 이유가 바로 [02 문서](./02_숫자와_문자는_어떻게_저장되나.md)의 주제입니다.

## 🧑‍🏫 강사용 — 60분 강의로 진행한다면

| 시간 | 내용 | 자료 |
|---|---|---|
| 0–10분 | `CacheLab` 실행: 같은 계산이 28배 차이 → "메모리는 멀다, DB는 더 멀다" → 반복문 안의 DB 호출 | 01 |
| 10–20분 | `NumberLab` 의 `0.1+0.2`, `EncodingLab` 의 `占쏙옙` — **화면에 깨진 글자를 띄우고 원인 맞히기 퀴즈** | 02 |
| 20–40분 | **핵심 데모** `SingletonStateBug`: 20명 중 18명이 남의 이름을 받음 → `RaceConditionLab` 으로 원리 설명 | 03, 04 |
| 40–50분 | `LostUpdateLab`: 트랜잭션을 써도 5,000원이 남는 장면 → 해결 2가지 | 06 |
| 50–60분 | `IndexLab`: 인덱스 하나로 약 150배, `LIKE '%값%'` 이면 다시 전체 스캔 | 06 |

> 💡 데모 팁: 결과를 보여 주기 전에 **"최종 잔액은 얼마일까요?"** 처럼 먼저 예측하게 하세요. 틀린 예측이 오래 기억에 남습니다.
> 레이스 컨디션 결과는 실행할 때마다 달라지므로 "왜 매번 다를까?"도 좋은 질문거리입니다.
